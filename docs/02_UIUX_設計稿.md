# 幸福好厝邊 ElderLink — UI/UX 設計稿

> 版本：v1.0　｜　設計主軸：溫暖、好厝邊、高齡友善　｜　平台：手機 App 風格 × 桌面網頁版

---

## 1. 設計原則（Design Principles）

1. **高齡友善優先**：大字級、大點擊區、高對比、少層級。任何主要動作都能一步完成。
2. **溫暖不冷硬**：暖橘珊瑚色系、圓角、握手意象，像「有溫度的好厝邊」。
3. **打一個字就有答案**：以搜尋為核心，弱化複雜導覽。
4. **在地感**：清楚呈現「你的地區」與「全國」，讓長輩安心。
5. **一致的雙端體驗**：手機 App 風格與桌面網頁版共用設計語言，於 940px 切換。

## 2. 品牌與視覺系統（Visual System）

### 2.1 色彩（Color Tokens）
| 用途 | 色碼 | 說明 |
|---|---|---|
| 主色（珊瑚橘） | `#E0552E` / `#F26B43` | 按鈕、重點、品牌 |
| 主色深（文字強調） | `#B23F1E` | 標題強調、連結 |
| 底色（暖白） | `#FAF6F2` / `#FFF4EF` | 頁面／卡片背景 |
| 主文字 | `#241F1B` | 標題 |
| 次文字 | `#574E47` / `#6E645C` | 內文／說明 |
| 邊框／分隔 | `#F0E6DE` / `#E4D7CC` | 卡片邊、分隔線 |
| 在地（綠） | `#2E7D52` / `#E7F4EC` | 「你的地區」徽章 |
| 全國（藍） | `#2A63C0` / `#EAF1FB` | 「全國」徽章 |

### 2.2 字級（Typography）
- 內文基準大（16px 起跳）、標題 18–28px、可放大字級（AA 按鈕）。
- 電話號碼採等寬數字（`tabular-nums`），易讀易撥。

### 2.3 形狀與陰影
- 圓角：卡片 14–18px、按鈕與徽章 999（膠囊）。
- 陰影：極輕（`0 2px 8px rgba(40,30,20,0.04)`），保持乾淨。

### 2.4 圖示（Iconography）
- 自製線性 SVG（ELIcon 元件），一致線寬。八大分類、功能、狀態各有對應 icon。
- App 圖示：橘底 + 白色握手（象徵「好厝邊」互助）。

## 4. 版面配置（Layout）

### 4.1 斷點
- **手機（≤ 940px）**：App 風格。頂部品牌列，底部固定五格導覽（首頁／圖卡／問答／新知／我的）。
- **桌面（> 940px）**：頂部橫向導覽列 + 內容區，寬版卡片網格。

### 4.2 首頁（Home）
- **手機**：品牌列 → 地區列（全台灣／變更地區）→「我需要什麼幫助？」搜尋框 → 教學卡 → 依分類瀏覽（含各分類筆數）→ 底部導覽。
- **桌面**：頂列導覽 →「需要幫長輩找資源？打一個字，馬上找到能打的電話。」Hero + 大搜尋框 + 熱門詞 → 教學卡 → 五格功能卡。

### 4.3 搜尋結果頁
- 返回鍵 + 搜尋框 + 珊瑚色「搜尋」鈕 + 語音鍵。
- 地區提示橫幅（偵測到地區且衝突時：切換／同名消歧／群組／未知地名）。
- 篩選膠囊：你的地區／全國／其他區域；排序（綜合排序／最近更新／依名稱）；分類膠囊。
- 結果卡：標題 + 地區徽章 + 摘要 + 一鍵撥打 + 地址 + 標籤。
- 找不到 → 建議詞 + 「用 LINE 問在地志工」CTA。

### 4.4 資源詳情頁
- 分類色左框卡；徽章（你的地區／全國）；電話大按鈕；地址；標籤；資料來源。
- 動作：收藏（跨裝置同步、計數）、分享給家人、回報資料有誤、說讚（compact）。

## 6. 互動設計（Interaction）

- **地區衝突才打擾**：只有偵測到地區且與目前選擇不同時，才跳提示；相同則直接搜。
- **同名地區消歧**：如「大安區」→ 直接列出〔台北市大安區〕〔台中市大安區〕讓使用者點。
- **語音輸入**：麥克風一鍵說出需求（Web Speech API）。
- **回上頁復原**：資源列表的篩選狀態以 sessionStorage 保存，返回時還原。
- **跨裝置同步**：收藏寫入 DB，手機與電腦一致。

---

## 7. LINE 對話介面設計（Conversational UI）

- **Rich Menu**：新手選單 → 設定地區後切換完整六大功能選單。
- **Flex Message 資源卡**：標題 + 地區標籤 + 摘要 + 撥打電話／查看詳情按鈕，可左右滑動的 carousel。
- **Quick Reply（底部固定）**：「目前地區：○○」（顯示用）＋「換地區」。
- **換地區確認卡**：偵測到不同地區 → 〔是，看○○〕〔否，維持原本〕。
- **安全分流訊息**：急症／輕生／受虐／詐騙以純文字優先直接回，附專線。

---

## 8. 無障礙與高齡友善（Accessibility）

- 提供「AA」放大字級、無障礙宣告頁、隱私與帳號安全頁。
- 語意化 HTML、可鍵盤操作、focus 樣式、`aria-label`。
- 色彩對比符合可讀性；電話、地址等關鍵資訊高辨識。

- 設計以程式內嵌樣式與 Tailwind 4 tokens 實作，元件化於 `src/components/`。

## 10. 元件狀態規格（Component States）

| 元件 | 狀態 | 視覺 |

| 按鈕（主要） | 一般／hover／disabled／loading | 珊瑚實心；loading 半透明、游標禁用 |

## 12. 設計決策紀錄（Design Decisions）

1. **搜尋為核心、弱化導覽**：長輩不擅長層層點選，改以「打一個字」為主入口。
2. **地區衝突才打擾**：避免每次都跳提示造成疲勞，只在真正需要時確認換地區。
3. **同名地區用點選消歧**：如「大安區」直接列出候選，降低誤判。
4. **相關度優先、地區次之**：最相關者先呈現，同分再套「全國→縣市→區」。
5. **LINE 免下載即用**：對不裝 App 的長輩，LINE 是最低門檻通路。
6. **安全優先於流程**：急症/情緒/詐騙訊息在最前面直接回應，不被查詢流程延誤。
7. **暖橘珊瑚 + 握手意象**：傳達「好厝邊」的溫暖與互助，而非冷硬的政府系統感。
