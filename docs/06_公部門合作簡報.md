# 緣起：從一個關懷行動開始

- **2024 概念發想**：台大團隊與中華民國老人福利推動聯盟（老盟）合作，關注獨居長者的孤獨。
- 老盟已有一群志工在照顧獨居長者——但服務現場仍有難題。
- **獨立開發成真**：由江易庭（Morris Chiang）將概念實作為**開源網站 + LINE 官方帳號**，並運用政府開放資料。

# 照顧者面對的三大挑戰

志工與家屬多半自己也是長者、不是專業社工，他們需要的是**陪伴與友誼的工具**，而不只是服務。

- ❌ **家屬照顧、志工拜訪沒經驗**（早期）
- ❌ **話題重複、活動點子有限**（中長期）
- ❌ **長輩提出具體需求時，不知如何回應**（長期）

# 一個故事：陳阿姨的第一次拜訪

68 歲的志工陳阿姨，第一次要拜訪獨居的 82 歲劉爺爺，很緊張：
「我該說什麼？他要是不開門怎麼辦？」

她打開 ElderLink，**溝通錦囊與破冰話題**讓她做好準備。

門開了。他們一起笑、分享故事，慢慢建立信任。
後來她帶著摺紙和繪本去陪伴，就像 ElderLink 建議的一樣。
當劉爺爺提到想立遺囑，她也在平台上幫他找到**法律資源**。

> ElderLink 不只解決問題，更讓人**連結、傾聽、一起微笑**。

---

# 技術亮點：不只是資源清單

**四層搜尋管線，讓長輩「打白話」就找得到**

1. 地區解析（縣市＋區、區域群組、同名消歧、偏鄉）
2. 口語→細標籤對照（救護車→民間救護車…）
3. 情境式安全分流（急症→119、詐騙→165、情緒→1925）
4. 相關度排序（最相關的浮上來）

**LINE 智慧客服**：長輩用最熟悉的工具，加好友即用、免下載 App。

# 運用的政府開放資料

**data.gov.tw 核心資料集**

- 長照 ABC 據點（#88270，約 1.4 萬筆）
- 全國老人福利機構名冊（#8572）
- 健保特約醫事機構（醫學中心/醫院/診所/藥局 #39280–39284）
- 社區照顧關懷據點（#159489 等）
- 居家護理機構、樂齡學習中心、各縣市假牙補助…

> 每筆資源標註來源，並提醒以官方公告為準

---

# 合作提案

1. **上架政府資料開放平台「資料活化應用」**，作為開放資料活化典範
2. **資料協作**：介接更即時、更完整的開放資料（更新頻率、欄位標準化）
3. **推廣合作**：與各縣市社會局／衛生局、社區據點合作，觸及在地長者
4. **共同精進**：以真實使用回饋，持續優化資源正確性與覆蓋
