## 投影片（05、06）如何轉成 PPTX / PDF

兩份簡報是 **Marp** 格式（Markdown 投影片），可用 marp-cli 一鍵轉檔：

```bash
npx @marp-team/marp-cli docs/05_使用者簡報_上線操作與LINE.md --pptx
npx @marp-team/marp-cli docs/06_公部門合作簡報.md --pdf
```

或在 VS Code 安裝「Marp for VS Code」擴充套件，直接預覽與匯出。
